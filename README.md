# Starlight Princess Demo\n\nAndroid için çevrimdışı oynanabilen, yalnızca sanal kredi kullanan bağımsız bir fantastik eşleştirme/slot demosu.\n\n## APK oluşturma\nGitHub Actions > Build Android APK > Run workflow. İşlem tamamlanınca ilgili çalıştırmanın Artifacts bölümünden `Starlight-Princess-Demo-APK` dosyasını indirin.\n\nBu proje özgün demo görselleri ve semboller kullanır; orijinal oyunun lisanslı varlıklarını içermez. Gerçek para veya ödeme özelliği yoktur.\n
